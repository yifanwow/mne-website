# Mne 网站 1.7.0 · NAS 文件替换

这个包是现有网站的静态文件更新，不包含 Docker 配置。网站内容对应 GitHub 上 Mne 0.9.190 (221)。

1. 在电脑解压 `mne-website-update-1.7.0.zip`。
2. 在 NAS 的 File Station 或 Finder 打开 `docker/mne-website`，先把现有 `site` 复制到旁边留作备份，例如 `site-backup-before-1.7.0`。
3. 打开原来的 `docker/mne-website/site`，将更新包 **`site` 里面的全部内容** 复制进去。同名文件选择替换，`assets` 文件夹选择合并并替换其中的同名文件。包里是完整静态站，不必逐个挑选改动文件。
4. 保留原 `site` 目录本身，不把它移走或删除后重建；这是运行中容器绑定的目录。不要覆盖项目旁边的 `docker-compose.yml`、`nginx.conf`，也不用更新 `mne-api`、`.env`、数据库、证书或反向代理。
5. 打开 https://mne.yifanovo.com/?v=1.7.0 ，浏览器强制刷新。如果仍显示旧页面，清除此站缓存后重开。静态文件挂载正常时会直接生效，**无需重新构建 Docker 镜像**。

## 更新后查看

- 02B 保留桌面四列和可编辑相册；默认相册名是汐声、林隙、浮光、远岫。下方快捷操作随页面下滑播放，上滑可回看，不需要操作界面中的每个按钮。
- 新增 02C「快速查重」与「告别图表」滚动演示；两者按 App 当前状态标为实验功能。演示使用固定示意照片／数据，不会访问图库或删除任何文件。
- 03 卡片分类数量是普通 12／主题 10／三星 6，七星和星火相传采用最新原画；五张神秘卡继续遮掩名称和故事。
- 开发手记顶部是 2026-10-20、0.9.190 (221)；这是源码进展，不代表当前构建已经公开发布。
- 手机检查标题、演示与步骤是否完整显示；系统减少动态效果时，可以直接点击 01—05 查看静态步骤。

仅更新网页不会更新 iOS App 或其后端。网站所有相册动作和数字都是示意。

## 回退

如果需要回退，将备份 `site` 内部的文件覆盖回原 `site` 目录；仍保留原目录本身。然后强制刷新浏览器。原 Docker、域名和证书配置不需要改。

`release.json` 记录此次网站和 App 来源、每个静态文件的 SHA-256。它供离线核对，不必上传到公开 `site` 里。
