# Mne 网站 1.9.2 · NAS 文件替换

这个包是现有网站的静态文件更新，不包含 Docker 配置。网站内容对应 GitHub 上 Mne 0.9.190 (221)。

1. 在电脑解压 `mne-website-update-1.9.2.zip`。
2. 在 NAS 的 File Station 或 Finder 打开 `docker/mne-website`，先把现有 `site` 复制到旁边留作备份，例如 `site-backup-before-1.9.2`。
3. 打开原来的 `docker/mne-website/site`，将更新包 **`site` 里面的全部内容** 复制进去。同名文件选择替换，`assets` 文件夹选择合并并替换其中的同名文件。包里是完整静态站，不必逐个挑选改动文件。
4. 保留原 `site` 目录本身，不把它移走或删除后重建；这是运行中容器绑定的目录。不要覆盖项目旁边的 `docker-compose.yml`、`nginx.conf`，也不用更新 `mne-api`、`.env`、数据库、证书或反向代理。
5. 打开 https://mne.yifanovo.com/?v=1.9.2 ，浏览器强制刷新。如果仍显示旧页面，清除此站缓存后重开。静态文件挂载正常时会直接生效，**无需重新构建 Docker 镜像**。

## 更新后查看

- 宽屏左侧目录文字放大，当前章节名称再大一级、略加字重；滚动页面时强调随位置切换。目录继续支持收起和跳转。

- 02A 到快速查重的标题统一为前半句主题紫、后半句白色，中英文同步；手机保持自然换行。

- 02A 标题为「回望，也可以纯粹且简单」。单张菜单随下滑展示长按、喜欢、加入相册、暂存及恢复；上滑可回看。
- 「不离开照片，把事情做好」只展示瀑布流操作，五步为浏览、浮起预览、喜欢、最近相册归档及回到浏览。
- 首页出现「遇见美好，留下回忆。」和「邀请制内测中」。宽屏目录靠近屏幕左边缘，无大块磨砂底板，与正文拉开距离。

- 设计理念位于 02A 前，强调操作、美学和正反馈。02A 单张演示带元数据、工具胶囊、状态标识和底部胶片条。
- 快捷操作／快速查重的滚动区域更紧凑、演示更大；上滑仍可回看。
- 回忆图谱默认 2017—2026 十年、24,680 份示意回忆，可切年份范围与图表。
- 紧接图谱是「告别仍有印记，见证岁月成长」：可操作两种日期口径、起止年份、时间粒度、图表和读数。选没有记录的年份会显示空态，累计总数保持不变。
- ≥1640 CSS px 的宽屏左侧显示可收起的章节目录；点击切换位置，刷新保留收起偏好。
- 28 张卡面及 App 最新手记保留；App 源码仍为 0.9.190 (221)。所有照片、数字与操作均为网页示意。

仅更新网页不会更新 iOS App 或其后端。网站所有相册动作和数字都是示意。

## 回退

如果需要回退，将备份 `site` 内部的文件覆盖回原 `site` 目录；仍保留原目录本身。然后强制刷新浏览器。原 Docker、域名和证书配置不需要改。

`release.json` 记录此次网站和 App 来源、每个静态文件的 SHA-256。它供离线核对，不必上传到公开 `site` 里。
