## Original Mne design

- `app-icon.png`: Dream Purple icon.
- `fool.png`, `keeper.png`, `curator.png`, `mornings.png`, `tides.png`, `seasons.png`, `moon.png`: the seven current V3 achievement artworks, optimized for the web without redrawing.
- `app-art.js`: SVG port of `MemoryBoxGeometry`, `ProfileStatisticSymbol` and `ProfileMeteorArt` coordinates. Original stroke weight, 0.88 inset, celestial shapes, detached meteor trails and lunar masks are preserved.
- `fragments-data.js`: app card names and original `MemorySeal.story` text, with Chinese translations from `AppLanguage`.
- Memory Atlas follows `MemoryDistributionView`, `MemoryPeriodPicker`, `MemoryRangePicker`, `MemoryDistributionChart` and `ProfileStatColumn`. SwiftUI cannot execute in the browser; this is a web implementation of those components, not an iOS screenshot.

Copyright remains with Mne. Private app source, account services, credentials, profiles and NAS configuration are not published.
