# Public assets

The website includes only the selected public-facing brand assets and demo photography. The private Mne repository, development documents, services, credentials, user profiles, invite codes and NAS configuration are not copied into this repository.

- `fool.png`, `keeper.png`, `moon.png`: three approved V3 achievement artworks from the Mne app. Source artwork remains unchanged; browser CSS adds the display glow.
