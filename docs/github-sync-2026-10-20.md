## 功能与界面依据

- `SimilarPhotoGroupRow.swift`：左侧大图优先保留，右侧两列对照，体积／日期／来源、组内选择与暂存恢复标记。网页仅采用一组、三个不同尺寸的同一作者作品作为示意，不运行 pHash 或假装读取真实媒体信息。
- `TimelineView+Similar.swift / SimilarScanControls`、`SimilarPhotoScanCache.swift`、10 月 19 日开发记录：实验功能无需密码；相似候选由用户选择，选择不等于删除；本机缩略图、不下载云端原件；结果与进度可缓存、暂停后主动继续，清理缓存会移除查重结果但保留暂存与个人记录。网页不许诺扫描耗时、准确率或零丢失。
- `FarewellDistributionView.swift`、`FarewellHistory.swift`：只读本机成功删除明细；按拍摄／告别日期、范围和时间粒度展示。累计总量可多于有日期覆盖；缺失旧日期不猜补。网页示意累计 72（照片 62／视频 10），有日期明细 54；日期口径切换总量不变，选 2026 后范围明细 36、累计仍为 72。不是“最近删除”或恢复已删照片入口。
- `MemorySeal.swift`、`AppLanguage.swift`、`docs/achievement-art.md`：28 张卡，普通 12／主题 10／三星 6；七星、星火相传采用最新正式透明原稿，女皇同步换稿。公开故事沿用模型／本地化，不展示条件；邀请归因尚未接入，开发手记保留这一状态。
- README 与 10 月 17—20 日文档：补齐四天网站手记；更新照片本体不上传、登录使用概况和用户主动确认错误报告的边界。没有把后台实现、旧构建或 GitHub 推送写成当前 App 或 NAS 已发布。
